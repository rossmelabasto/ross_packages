v@VERSION:ross-record@ · Linux · terminalterminal

record

A microphone recorder for the terminal, with a live level meter. Talk, press Ctrl+C, and it offers to turn what you said into text with transcribe: on screen, as a .txt with timestamps, or not at all.

Una grabadora de micrófono para la terminal, con medidor de nivel en vivo. Hablas, presionas Ctrl+C y te ofrece convertir lo que dijiste en texto con transcribe: en pantalla, como .txt con tiempos, o nada.

Install

Instalar

From the signed repository. SoX, pactl and Perl come as dependencies. If you install transcribe, record comes with it.

Desde el repositorio firmado. SoX, pactl y Perl llegan como dependencias. Si instalas transcribe, record viene con él.

If you haven't added the repository yet, do that first (one time). Then:

Si todavía no agregaste el repositorio, hazlo primero (una sola vez). Luego:

sudo pacman -Syu ross-record

If you haven't added the repository yet, do that first (one time). Then:

Si todavía no agregaste el repositorio, hazlo primero (una sola vez). Luego:

sudo apt update && sudo apt install ross-record

If you haven't added the repository yet, do that first (one time). Then:

Si todavía no agregaste el repositorio, hazlo primero (una sola vez). Luego:

sudo dnf install ross-record

Without the repository: it's one Bash script, bin/record in the source code.

Sin el repositorio: es un solo script de Bash, bin/record en el código.

Use

Uso

record                      # record until Ctrl+C, then: transcribe, save a .txt or nothing
record -s -t idea           # start when you speak, stop after 3 s of silence, transcribe
record networks-class -c -o # clean up the audio and save the transcript next to it
record -d 1:00 -L en        # record exactly one minute, English transcript
record -l                   # list microphones; -i <name> picks one

Recordings go to ~/Recordings, or to the folder in RECORD_DIR. -c removes low rumble and normalizes the volume; -f picks ogg, flac, wav or mp3; -n records without asking anything, for scripts and hotkeys.

Las grabaciones van a ~/Recordings, o a la carpeta de RECORD_DIR. -c quita el ruido grave y normaliza el volumen; -f elige ogg, flac, wav o mp3; -n graba sin preguntar nada, para scripts y atajos. Sus mensajes están en inglés.
