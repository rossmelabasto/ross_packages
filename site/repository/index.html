Add the repository

Agregar el repositorio

There are two. [ross] has my programs and works on any distribution. [ros] has the packages of rOS itself and is only meant for rOS.

Hay dos. [ross] tiene mis programas y funciona en cualquier distribución. [ros] tiene los paquetes del propio rOS y es solo para rOS.

Programs: [ross]

Programas: [ross]

Add it once and then install any program from it, like ross_visualizer.

Lo agregas una vez y desde ahí instalas cualquier programa, como ross_visualizer.

Import and trust the signing key, then add the repository to /etc/pacman.conf:

Importa y confía en la clave de firma, y agrega el repositorio a /etc/pacman.conf:

curl -fsSL https://repo.rossmel.com/key.asc | sudo pacman-key --add -
sudo pacman-key --lsign-key C08F57FCE06B95B52145012C274187B9D5E9FFEB
printf '\n[ross]\nServer = https://repo.rossmel.com/arch/x86_64\n' | sudo tee -a /etc/pacman.conf
sudo pacman -Sy

To remove it, delete the [ross] block from /etc/pacman.conf.

Para quitarlo, borra el bloque [ross] de /etc/pacman.conf.

Ubuntu 22.04 or newer, Debian 13, Linux Mint and Pop!_OS:

Ubuntu 22.04 o más nueva, Debian 13, Linux Mint y Pop!_OS:

curl -fsSL https://repo.rossmel.com/key.asc | sudo gpg --dearmor -o /usr/share/keyrings/ross.gpg
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/ross.gpg] https://repo.rossmel.com/apt stable main" | sudo tee /etc/apt/sources.list.d/ross.list
sudo apt update

To remove it: sudo rm /etc/apt/sources.list.d/ross.list /usr/share/keyrings/ross.gpg

Para quitarlo: sudo rm /etc/apt/sources.list.d/ross.list /usr/share/keyrings/ross.gpg

sudo curl -fsSL https://repo.rossmel.com/rpm/ross.repo -o /etc/yum.repos.d/ross.repo

The first time you install from it, dnf asks whether you trust the key. Check that the fingerprint matches the one below.

La primera vez que instalas desde ahí, dnf pregunta si confías en la clave. Revisa que la huella coincida con la de abajo.

To remove it: sudo rm /etc/yum.repos.d/ross.repo

Para quitarlo: sudo rm /etc/yum.repos.d/ross.repo

rOS packages: [ros]

Paquetes de rOS: [ros]

For rOS and Arch-based systems that want to try its pieces. These packages change the desktop and the system defaults, so add them knowing that rOS is still in development. The second Server is a mirror on GitHub Releases.

Para rOS y sistemas basados en Arch que quieran probar sus piezas. Estos paquetes cambian el escritorio y los valores por defecto del sistema, así que agrégalos sabiendo que rOS sigue en desarrollo. El segundo Server es un espejo en GitHub Releases.

curl -fsSL https://repo.rossmel.com/ros.gpg | sudo pacman-key --add -
sudo pacman-key --lsign-key ACEE9BCE9F03BA05E7B04DBAA56F95B047B9D345
sudo tee -a /etc/pacman.conf <<'EOF'

[ros]
SigLevel = Required DatabaseRequired
Server = https://repo.rossmel.com/$arch
Server = https://github.com/rossmelabasto/ross_packages/releases/download/$arch
EOF
sudo pacman -Sy

Moved from ros.rossmel.com

Si lo agregaste en ros.rossmel.com

The program repository used to live at ros.rossmel.com, which is now the home of rOS. The old address keeps working for a while, but switch to the new one when you can:

El repositorio de programas antes vivía en ros.rossmel.com, que ahora es la página de rOS. La dirección vieja sigue funcionando un tiempo, pero cámbiala a la nueva cuando puedas:

# pacman
sudo sed -i 's#ros.rossmel.com/arch#repo.rossmel.com/arch#' /etc/pacman.conf
# APT
sudo sed -i 's#ros.rossmel.com#repo.rossmel.com#' /etc/apt/sources.list.d/ross.list
# DNF
sudo curl -fsSL https://repo.rossmel.com/rpm/ross.repo -o /etc/yum.repos.d/ross.repo

The packages and the key are the same, so nothing gets reinstalled.

Los paquetes y la clave son los mismos, así que no se reinstala nada.
