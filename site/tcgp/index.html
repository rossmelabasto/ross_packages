ross_tcgp

The game has no export, so this drives the phone: over adb it scrolls the My Cards screen of Pokémon TCG Pocket, recognises every card against ~4,600 official images, reads how many copies you own and saves it all as JSON. Then --quick only reads your new packs, in about 15 seconds.

El juego no tiene exportación, así que esto maneja el teléfono: por adb recorre la pantalla My Cards de Pokémon TCG Pocket, reconoce cada carta contra ~4.600 imágenes oficiales, lee cuántas copias tienes y lo guarda todo en JSON. Después, --quick lee solo tus sobres nuevos, en unos 15 segundos.

Install

Instalar

From the signed repository. It uses your system's Python, Pillow, NumPy and adb, which come as dependencies.

Desde el repositorio firmado. Usa el Python, Pillow, NumPy y adb de tu sistema, que llegan como dependencias.

If you haven't added the repository yet, do that first (one time). Then:

Si todavía no agregaste el repositorio, hazlo primero (una sola vez). Luego:

sudo pacman -Syu ross-tcgp

If you haven't added the repository yet, do that first (one time). Then:

Si todavía no agregaste el repositorio, hazlo primero (una sola vez). Luego:

sudo apt update && sudo apt install ross-tcgp

If you haven't added the repository yet, do that first (one time). Then:

Si todavía no agregaste el repositorio, hazlo primero (una sola vez). Luego:

sudo dnf install ross-tcgp

Then run ross-tcgp update once: it downloads the card data and reference images (~70 MB) into ~/.cache/ross_tcgp. No game images are shipped in the package.

Luego corre ross-tcgp update una vez: descarga los datos de las cartas y las imágenes de referencia (~70 MB) a ~/.cache/ross_tcgp. El paquete no trae ninguna imagen del juego.

Use

Uso

Enable USB debugging on the phone, connect it, open the game on My Cards and don't touch it while it scans:

Activa la depuración USB en el teléfono, conéctalo, abre el juego en My Cards y no lo toques mientras escanea:

ross-tcgp scan             # the whole collection (~5 min for ~900 cards)
ross-tcgp scan --quick     # only new cards: sort the game list by "Recent cards" first
ross-tcgp show --name pika # list what you own
ross-tcgp show --json      # the raw JSON, for other tools
ross-tcgp diff OLD.json    # what changed since an older scan

Every scan is saved in ~/.local/share/ross_tcgp and compared with the previous one: new cards and extra copies are listed at the end.

Cada escaneo se guarda en ~/.local/share/ross_tcgp y se compara con el anterior: al final lista las cartas nuevas y las copias extra. Sus mensajes están en inglés.
