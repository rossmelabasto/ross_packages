ross_fisheye

A fisheye magnifier for Wayland. Press a shortcut and the screen freezes under a lens that bulges it like cloth pushed up by a glass ball: no hard edge, the middle stretched, the slope lit from above. Press it again to close it.

Una lupa de ojo de pez para Wayland. Aprietas un atajo y la pantalla se congela bajo una lente que la abomba como una tela empujada por una bola de cristal: sin borde duro, el centro estirado y la ladera iluminada desde arriba. Lo aprietas otra vez y se cierra.

Which desktops? It needs the wlr-screencopy protocol: niri, Hyprland, Sway, river, Wayfire and others have it. GNOME and KDE Plasma don't, so it won't open there.

¿En qué escritorios? Necesita el protocolo wlr-screencopy: lo tienen niri, Hyprland, Sway, river, Wayfire y otros. GNOME y KDE Plasma no, así que ahí no abre.

Install

Instalar

From the signed repository. If you haven't added it yet, do that first (one time). Then:

Desde el repositorio firmado. Si todavía no lo agregaste, hazlo primero (una sola vez). Luego:

sudo pacman -Syu ross-fisheye-bin
sudo apt update && sudo apt install ross-fisheye
sudo dnf install ross-fisheye

Shortcut and full screen

Atajo y pantalla completa

Give it a shortcut, and a window rule so the lens covers the whole screen (with fractional scaling it can't ask for full screen by itself).

Dale un atajo y una regla de ventana para que la lente cubra toda la pantalla (con escala fraccional no puede pedir la pantalla completa sola).

In ~/.config/niri/config.kdl: the shortcut inside binds { }, the rule at the top level.

En ~/.config/niri/config.kdl: el atajo dentro de binds { } y la regla afuera.

Mod+Shift+Z hotkey-overlay-title="Magnifier" { spawn "ross-fisheye"; }

window-rule {
    match title="^ross-fisheye$"
    open-fullscreen true
}

In ~/.config/hypr/hyprland.conf:

En ~/.config/hypr/hyprland.conf:

bind = SUPER SHIFT, Z, exec, ross-fisheye
windowrulev2 = fullscreen, title:^(ross-fisheye)$

In ~/.config/sway/config, then swaymsg reload:

En ~/.config/sway/config, y luego swaymsg reload:

bindsym Mod4+Shift+z exec ross-fisheye
for_window [title="^ross-fisheye$"] fullscreen enable

It opens on the focused screen (niri, Hyprland and Sway) and shows a still picture taken when it opened. ross-fisheye --zoom is woomer's classic zoom: drag, scroll, and hold Ctrl for a spotlight.

Abre en la pantalla enfocada (niri, Hyprland y Sway) y muestra una foto fija tomada al abrirse. ross-fisheye --zoom es el zoom clásico de woomer: arrastras, usas la rueda y mantienes Ctrl para el foco.
