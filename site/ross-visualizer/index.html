ross_visualizer

Listens to everything your computer plays and paints it with the colors of the album art. Full screen, or as an overlay above your windows that lets clicks through. No audio source to pick and no account to sign in to.

Escucha todo lo que suena en tu compu y lo pinta con los colores de la portada. En pantalla completa o como overlay encima de tus ventanas, que deja pasar los clics. Sin elegir fuente de audio y sin iniciar sesión.

Will it work on my computer?

¿Va a funcionar en mi compu?

This checks your system and tells you which features will work. It only reads: it installs nothing, asks for no password and sends nothing anywhere. Run it from a terminal on your desktop.

Esto revisa tu sistema y te dice qué funciones van a andar. Solo lee: no instala nada, no pide contraseña y no envía datos a ningún lado. Córrelo desde una terminal de tu escritorio.

Install

Instalar

From the signed [ross] repository: you add it once and updates arrive with the rest of your system.

Desde el repositorio firmado [ross]: lo agregas una vez y las actualizaciones llegan con las del resto de tu sistema.

Add the repository and install

Agregar el repositorio e instalar

curl -fsSL https://repo.rossmel.com/key.asc | sudo pacman-key --add -
sudo pacman-key --lsign-key C08F57FCE06B95B52145012C274187B9D5E9FFEB
printf '\n[ross]\nServer = https://repo.rossmel.com/arch/x86_64\n' | sudo tee -a /etc/pacman.conf
sudo pacman -Syu ross-visualizer-bin

Download the AppImage of version @VERSION:ross-visualizer@, make it executable and run it. It works on any distribution, but it doesn't update itself and your system still needs pipewire and playerctl.

Descarga el AppImage de la versión @VERSION:ross-visualizer@, hazlo ejecutable y ábrelo. Sirve para cualquier distribución, pero no se actualiza solo y tu sistema igual necesita pipewire y playerctl.

chmod +x ross_visualizer_@VERSION:ross-visualizer@_amd64.AppImage
./ross_visualizer_@VERSION:ross-visualizer@_amd64.AppImage

The first time you open it, a short tour shows the scenes, the overlay and the keyboard shortcuts for your desktop.

La primera vez que la abres, un tutorial corto te muestra las escenas, el overlay y los atajos de teclado para tu escritorio.

Keyboard shortcuts

Atajos de teclado

Two shortcuts turn the overlay on and switch its style from anywhere, without opening the app. Every desktop keeps its shortcuts in its own config, so the app can't add them itself.

Con dos atajos prendes el overlay y cambias de estilo desde cualquier lado, sin abrir la app. Cada escritorio guarda sus atajos en su propia configuración, así que la app no puede agregarlos sola.

ShortcutAtajoDoesQué hace
Super+Ctrl+VTurns the overlay on or offPrende o apaga el overlay
Super+Ctrl+BNext overlay styleSiguiente estilo de overlay

Inside the binds { } block of ~/.config/niri/config.kdl. niri picks them up when you save.

Dentro del bloque binds { } de ~/.config/niri/config.kdl. niri las toma al guardar.

Mod+Ctrl+V hotkey-overlay-title="Visualizer: overlay on/off" { spawn "ross-visualizer" "overlay" "toggle"; }
Mod+Ctrl+B hotkey-overlay-title="Visualizer: next overlay style" { spawn "ross-visualizer" "overlay" "next"; }

In ~/.config/hypr/hyprland.conf. Hyprland picks them up when you save.

En ~/.config/hypr/hyprland.conf. Hyprland las toma al guardar.

bind = SUPER CTRL, V, exec, ross-visualizer overlay toggle
bind = SUPER CTRL, B, exec, ross-visualizer overlay next

In ~/.config/sway/config, then run swaymsg reload.

En ~/.config/sway/config, y luego corre swaymsg reload.

bindsym Mod4+Ctrl+v exec ross-visualizer overlay toggle
bindsym Mod4+Ctrl+b exec ross-visualizer overlay next
  1. Open System Settings → Keyboard → Shortcuts.
  2. Add New → Command or Script. Paste the first command and give it Meta+Ctrl+V.
  3. Do the same with the second command and Meta+Ctrl+B.
  1. Abre Preferencias del sistema → Teclado → Atajos.
  2. Añadir nuevo → Comando o script. Pega el primer comando y asígnale Meta+Ctrl+V.
  3. Repite con el segundo comando y Meta+Ctrl+B.
ross-visualizer overlay toggle
ross-visualizer overlay next

In your desktop's settings, give each command a shortcut. GNOME and X11 have no overlay, so you don't need them there.

En la configuración de tu escritorio, asigna un atajo a cada comando. En GNOME y en X11 no hay overlay, así que no hacen falta.

ross-visualizer overlay toggle
ross-visualizer overlay next

With the AppImage, replace ross-visualizer with the file's path. With no setup at all: right-click the app's icon in your launcher or dock and pick "Overlay on/off" or "Next overlay style".

Con el AppImage, cambia ross-visualizer por la ruta del archivo. Sin configurar nada: clic derecho en el ícono de la app en tu lanzador o dock y elige "Overlay sí/no" o "Siguiente estilo de overlay".
